# Material oficial pendiente

El acceso a las fuentes oficiales de HBO Max, WBD y YouTube devolvió HTTP 403 en el proxy del entorno. No se han descargado ni validado clips de películas.

Selección propuesta, pendiente de comprobar su disponibilidad actual en el catálogo local y de localizar sus tráilers oficiales:

- `dune.mp4`: Dune: Parte Dos, 8 segundos seleccionados.
- `batman.mp4`: The Batman, 7 segundos seleccionados.
- `dragon.mp4`: La casa del dragón, 7 segundos seleccionados.

Los archivos deben ser segmentos ya seleccionados, con el encuadre principal dentro de la zona central para el formato 9:16. La composición conserva el movimiento del material original y añade títulos. Se deben registrar aquí los enlaces oficiales exactos, los tiempos de entrada/salida y los créditos cuando se obtengan.

`npm run render:final` comprueba que estén presentes los tres archivos antes de exportar. El avance `Avance3D` solamente muestra la apertura y el cierre originales y no incluye escenas de estas producciones.
