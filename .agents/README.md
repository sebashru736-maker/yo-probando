# Habilidades creativas del proyecto

Las 18 habilidades de `skills/` se instalaron a petición del usuario para video, web y 3D. Se conserva la procedencia y el commit de cada paquete en `skills/PROVENANCE.json`, y sus licencias cuando forman parte del paquete original.

Son instrucciones para agentes dentro de este repositorio. No instalan aplicaciones en la PC del usuario ni añaden herramientas globales a su cuenta de ChatGPT.

Para el trabajo de video actual, consultar `estudio-creativo/README.md` y cargar `skills/remotion-best-practices/SKILL.md`. Para diseño web, cargar `skills/frontend-design/SKILL.md` y las habilidades de Three.js pertinentes.

La revisión V6 añade `video-router` para decidir entre edición del metraje aportado, composición y generación. Es una guía de producción; la restauración de imagen y la locución se ejecutan con modelos y herramientas reales documentados en `estudio-creativo/produccion-v6`.
